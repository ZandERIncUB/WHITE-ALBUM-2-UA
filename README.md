# Український переклад White Album 2 — 0.1.5

Це окремий пакет перекладу для японської версії гри. Він містить українські сценарії основної гри та IC, імена персонажів, потрібні шрифти, виправлений `WA2.exe` та `en.pak` з українськими елементами інтерфейсу. Пакет не замінює шість архівів графіки (`bak.pak`, `char.pak`, `grp.pak` та їхні відповідники в `IC`). Для ремастереної графіки є окремий пакет `White_Album_2_Graphics_patch_1.0.0.zip`.

## Встановлення

1. Розпакуйте ZIP в окрему папку. Закрийте гру.
2. Запустіть `Install_UA.cmd` і вкажіть папку японської гри з `WA2.exe`.
3. Якщо в цій папці вже встановлений попередній український патч, запустіть у PowerShell `install.ps1 -GameDir "шлях_до_гри" -Upgrade`.
4. Запускайте гру через Locale Emulator з японською локаллю.

Графічний пакет можна встановити до або після перекладу: він змінює тільки шість архівів графіки. Locale Emulator не входить до пакета.

Інсталятор перевіряє сумісність `WA2.exe`, потрібні архіви та контрольні суми всіх файлів перекладу до внесення змін. Початкові файли він переносить до `WA2_UA_Backup_дата_час` у папці гри. Шлях до копії записаний у `WA2_UA_install.json`. Збереження гри не змінюються.

## Відновлення

Закрийте гру. Приберіть встановлені патчем `WA2.exe`, `d3d9.dll`, `en.pak` та папки `script`, `IC/script`, `fnt`, `todokanai`, якщо вони є. Поверніть відповідні файли й папки з `WA2_UA_Backup_дата_час`. Не видаляйте папку `IC` цілком: там залишаються архіви гри.

## Стан перекладу

Пакет зібраний із наявних українських карт перекладу всіх сценарних файлів основної гри та IC. Окремі ресурси базового патча можуть залишатися російською або японською; це ще не остаточна редакторська перевірка всього тексту.

## Для збирачів

`make_release.py` збирає цей пакет із `japanese_script_extract`, `japanese_ic_script_extract`, `translations_uk` та перевірених ресурсів. Для доданих гліфів використано Open Sans за ліцензією OFL (`OFL_OpenSans.txt`).
